# 协作与任务交接

[中文](collaboration.zh-CN.md) | [English](collaboration.md)

Codex 与 Claude 共用[项目规则](../AGENTS.md)、[运行说明](../README.md)和
[架构约定](architecture.zh-CN.md)。任务决定写入交接记录。聊天的私有上下文
不能代替交接记录。更换负责人或工具后，既有授权和未通过的验收条件继续有效。

## 开始任务

1. 明确唯一负责人、允许修改的范围和审查方。每项任务使用一个工作树和一个分支。
   同一文件保持一个写入者。每台机器一次运行一项重数值计算；独立轻量任务可以并行。
2. 协调者检查主目录，将干净的 `main` 快进同步，并记录起点提交。遇到本地修改或
   历史分叉时，先保留并检查差异，再决定如何整合。
3. 从该提交建立任务分支，登记工作树和分支。Codex 分支默认使用 `codex/` 前缀；
   用户另有指定时按用户要求命名。
4. 通过任务目录中忽略的 `.venv-path` 选择解释器。共享环境只承载依赖，位于任务
   工作树之外。适用锁文件一致时才能共用。环境相关工作开始前通过锁检查和 `pip check`。
5. 项目源码从当前工作树导入。Matplotlib、XDG、Numba 和原生物性表缓存放在本工作树
   忽略的 `.cache/` 中。另行记录实际原生库及其源码、构建身份。检查是否仍引用待移除工作树。

创建或调整环境需要用户授权。收到明确请求后，在最终位置按适用精确锁建立环境。
先验证新环境，再切换活动指针；切换验收通过前保留原环境。BO 和桌面打包环境
分别使用自己的锁文件和验收检查。

## 同步与审查

负责人完成相关检查后，在授权范围内提交、推送并创建 PR。提交内容不含本地数据、
环境和探索报告。简要交接记录放在 PR 描述中；PR 创建前需要交接时，使用指定的
issue。本机绝对路径和详细证据保存在本地忽略的记录中。

审查针对明确的分支提交，修订由负责人完成。审查后增加提交，需要更新审查结论。
若 `main` 前进，负责人将当前 `origin/main` 合入任务分支，解决冲突，并重跑受影响
检查及必需 CI。保留分支历史，不强推或覆盖其他负责人的改动。

仅在用户授权和仓库保护规则允许时合并。核对远端合并提交及对应 `main` 的 CI 最终
结果。随后由协调者快进同步干净的主目录，更新交接记录。PR CI、合并后主线 CI、
桌面验收和实验精度分别记录结论。

## 交接记录

共享 PR 或 issue 使用以下字段。负责人、范围、审查提交或下一步改变时更新记录。

| 字段 | 必填内容 |
| --- | --- |
| 任务 | 目标、允许修改的模块/文件、授权范围 |
| 人员或工具 | 负责人、审查方、整合协调者 |
| 代码 | 起点提交、分支、当前提交、审查提交、PR |
| 运行条件 | 适用锁、环境用途、原生构建、数据版本 |
| 证据 | 检查项目、对应提交、结果、本地证据记录名称 |
| 状态 | 已完成内容、失败项、未通过的门槛、待批准事项 |
| 下一步 | 具体动作及其负责人 |

本地私有记录补充工作树、解释器、原生库、数据链接目标和证据路径。保留原始失败
和未运行状态。接手方先读共享记录，并核对本机路径，再执行命令。向其他聊天发送
消息需要用户授权该通信。

## 归档与清理

移除工作树前，确认所属任务、写入者和运行进程、未提交或未推送内容、运行资源
使用方及 ignored 证据。在移除范围之外保存必要提交和本地材料，记录原路径、提交、
锁文件、成员清单和链接目标。归档工作树时不跟随原始数据链接。

逐文件核对归档与原件，并实际恢复、读取代表性报告和输入输出文件。现存缺失或
格式损坏单独记录，不改变历史结论。同盘归档不算独立备份；应用的 Git 快照不能
代替 ignored 证据归档。

上述验收通过且活动使用方为零后，才能移除工作树或环境。使用其所属应用或对应的
Git 工作树管理操作。最后处理分支，先确认必要提交有恢复入口。旧筛选结果只归档，
不恢复已退役的求解或优化链；当前多工况 BO 继续作为独立能力维护。

## 工具规则入口

[Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md) 读取 `AGENTS.md`。
支持 AGENTS 的 [Claude Code](https://code.claude.com/docs/en/memory#agentsmd) 版本在
项目或上层目录没有 `CLAUDE.md` 覆盖该选择时，可以直接读取它。首次接入时在实际
客户端检查规则加载。若既有 Claude 配置需要入口，在 `CLAUDE.md` 中用 `@AGENTS.md`
引用共同规则，不复制出第二套规则。客户端接入和双任务协作试运行分别保留执行证据。
