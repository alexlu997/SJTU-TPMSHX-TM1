## 目标与范围

沿用前处理 → CaseData → 求解 → FieldResult → 后处理的现有模块边界。
完整二维、三维求解是主线；快速设计、筛选/优化只迁移受影响的消费者并做兼容回归。
公共逻辑集中维护，维度或物理机制确有差异的实现保留明确边界。

- 保留 GUI、CLI、公开 API，以及正式配置和结果文件的结构。
- 迁移仓库内消费者后，允许退役旧接口和旧收敛判据。
- 不新增工质、几何、相态或实验精度目标，不扩大物性及关联式适用域。
- 软件回归参考和比较容差允许按已解释的差异更新；旧参考、原失败与对照证据保留。
  更新记录需列出原因、适用比较量、实际变化和新容差依据。
- 回归参考更新不代替收敛、质量/能量守恒、网格误差和物理适用性检查。
  求解停止条件、物理判据和软件比较容差分别记录。
- 实现统一与性能冲突时，依据同条件测量决定保留专用实现或复用公共实现。

## 初始调用与差异矩阵

| 对象 | 当前归属与调用 | 本轮边界 |
|---|---|---|
| 公开运行入口 | `solvers/api.py` 按完整/快速设计/筛选模式，再按维度分派 | 保留公开入口与正式交接 |
| 动量求解 | 完整 2D 共用 `SIMPLESolver`；完整 3D 共用 `SIMPLESolver3D` | 不按工质复制新求解器 |
| 外层循环 | 两维度均用 `coupling_skeleton.run_outer_coupling`；循环体、物性更新时机不同 | 复用现有循环支持，验证实际状态来源 |
| 物性与关联式 | `models/fluid_props.py` 注册物性；Nu、D-F 有独立归属及适用范围 | 不借结构整理更换物性或重新拟合关联式 |
| 真实焓 | 含 sCO2 的完整工况；2D 适配器调用共用 3D 面通量焓内核 | 保留热力学状态、符号面流量及适用域检查 |
| 2D 模型焓 | 无 zone、无 offset，A/B 均为空气或水 | 包括水—水；保持现有选择条件 |
| 3D 模型焓 | Nz>1、变物性、双流体、无规定 B 温度，空气—空气/空气—水/水—空气，且满足 conservative/offset/chi 条件 | 当前未包含水—水；不自动扩大分支 |
| 其他温度路径 | 不满足上述选择条件的既有温度内核及其模式约束 | 审查、记录并保留其物理差异 |
| 收敛 | 完整求解默认 F2；原始求解类、筛选和部分验证还可用 legacy/LowReExit | 迁移并验证消费者后退役旧判据 |
| 网格与边界 | 准备阶段拥有实际网格/开口；动量、热量和后处理消费对应原生状态 | 2D 无厚度壁面，3D Nz=1 仍有 z 壁面；W/m 与 W 不混用 |
| 历史结果 | `data/local_evidence/` 保存数值、误差和性能对照 | 本地复用，不上传原始数据或大计算证据 |

## 验证安排

优先运行与变更直接相关的既有测试，覆盖公共入口、配置/文件交接、两维度 F2、
耦合、热输运和取消；筛选、快速设计及验证工具按消费者变化补充回归。
共享内核的完整阶段验收使用既有 sCO2 固定 166 项与上海水—空气 32 项，
核对受影响混合工质、流向、局部端口及失败路径的额外覆盖。

性能对照复用现有 sCO2/上海二维、三维代表工况、锁定环境及线程配置，
区分编译冷启动、预热后求解和完整流程。计时比较固定输入与验收条件；
有争议的差异再做交错重复，避免把噪声当成退化或提速。

研究中出现需要改变物理假设的新问题，单列复现实例和数值对照；
不将尚无证据的模型调整混入结构整理。
