# V0.1 需求追踪与节点归属

来源为用户提供的 V0.1 原文（副本转录见 V01_SOURCE.md）及后来明确的两项不可变原则、Python/C++/OpenFOAM三路线。本表是实施映射，不修改原文优先级或分期措辞。

| 原文或用户要求 | 对应节点 | 完成含义 |
|---|---|---|
| 三模块相互独立、标准数据通信 | G10、P/S/R/H、I20/I30、V20/V30/V40、Z00 | 真实分进程、最小依赖与契约证据 |
| 核心可独立计算，也供设计/参数/拓扑优化/GUI调用 | A10–A40、I51–I56 | 外部脚本与现有应用通过公开入口真实工作 |
| 工作流统一组织，不使应用依赖具体求解器 | G10、A10、I51/I56 | 工作流只编排，无重复物理流程 |
| Python/Numba路线保留 | S20/S30/S40、I20/I30/I40 | 现有能力和原拒绝范围明确保留 |
| C++与OpenFOAM并列后端 | X10/X11、X20/X21/X22 | 实际求解和交叉验证，不以接口占位完成 |
| 其他外部求解器扩展 | G10、后续实际接入子节点 | 保留公共接口；无具体需求不虚构适配器 |
| 宏观几何与可选微观几何 | P20/P30/P40、M00 | 保留“可选”；微观识别不混入正常宏观循环 |
| 网格、材料、流体与边界 | G10、P20/P30、M00 | 实际网格/边界交付；读取网格不等于后端支持求解 |
| 实验/CFD/DNS清洗拟合 | P40 | 离线入口与来源管理，普通求解不强制重拟合 |
| 均质化参数计算、读取、插值与Case构建 | M00、P20/P30/P40 | 固定参数/运行时模型分工、模型版本可解析 |
| 后端无关的均质化中间层 | G10、M00、X20 | 公共物理表达与后端格式转换分开 |
| 方向性参数优先张量表达 | G10、X30及后续模型子节点 | 表达有坐标语义；不等于已实现各向异性离散 |
| 物性与控制方程解耦 | M00、S20/S30、I55、V40 | 单一模型权威、无硬编码散落、不强制跨语言逐单元回调Python |
| 常物性/表格/拟合/CoolProp/REFPROP/用户模型 | M00、X30 | 已实现项验证；许可/模型缺口未完成，不静默删去 |
| sCO2 的 T–P 强变物性 | G10、M00、S/R、I/V | 运行时正确评估，保持实际状态/通量与已有检查 |
| FVM数值内部职责拆分 | S20/S30/S40、I20/I30/I40 | 保留独立内核职责，不把所有函数重新塞进一个大对象 |
| Darcy→DF→各向异性、LTE→LTNE逐步支持 | G10能力表、X30/后续模型节点 | 保留“逐步”，现有较完整能力不倒退重写，新增模型独立验证 |
| Q/ΔP/Tout与核心指标 | H10、R20/R30、I20/I30 | 从证据独立计算，不仅转抄原摘要 |
| h/Re/Nu/f/PEC等指标 | H30 | 已知定义复用；未给出的物理定义不能擅自填入 |
| 场读取、可视化与报告 | D20/H20/I52/I56/V40 | 求解退出后无需数值后端仍可运行 |
| case.yaml、case.h5、results.h5、results.vtk、metrics.json | D10/D20/H20/V20/V30 | 实际格式、回读、状态与资源齐备 |
| SI、schema_version | G10/D10/D20/I/V、X30/Z10 | M-A 新协议SI、旧叶内核显式适配；M-B 对剩余内部单位迁移逐项验收，不把原文全部内部SI降为仅文件SI |
| 可用pybind11、必要时C API | X10 | 方式按真实后端需要选择；不把“可以”变成所有方式均须实现 |
| 拓扑优化只改变设计场/均质化参数场 | G10/A30/I53 | 支持范围内公开数据传入，不改内部矩阵或私有系数 |
| 第一阶段仅预留梯度/伴随 | G10/A30/I53 | 明确未实现能力，不生成虚假梯度 |
| DOE/GA/PSO/NSGA-II/贝叶斯/梯度/代理可扩展 | A30/I53、后续应用 | 保留“可扩展”，不要求本轮重写所有算法 |
| 建议目录、测试、示例和文档 | 全图、Q10、Z00/Z10 | 职责为主；不强制先改成C++主目录或拆仓库 |

## 完成状态规则

M-A 只覆盖当前 Python 架构与已用应用能力，不要求真实 C++/OpenFOAM 或高级指标已完成。M-B 必须核查原文明示的当前必需能力；必需项没有实现/许可/真实测试时保持未完成。只有原文已写为逐步、可选、可扩展、必要时或仅预留的事项，才可保留对应阶段性状态而不谎称实现。

研究数据缺失不能用合成数据填补；合成样例只用于接口测试。已有物理精度数字不得自动继承到重构后新增模型或新后端。
