## 本包的静态检查工具

本包提供 `tools/check_graph.py`，只检查 DAG/任务卡/所有权、列拓扑就绪节点及受影响后继，不会启动 Agent、运行求解器、创建 PR 或后台调度。使用执行环境允许的解释器运行：

```text
python tools/check_graph.py validate
python tools/check_graph.py summary
python tools/check_graph.py ready
python tools/check_graph.py impact X21
```

在项目工作区遵守 .venv-path 规则；不要将这里的示意命令用作绕过解释器检查的理由。读取 JSON 本身不需要运行项目数值代码。
