## 不能沿用的归因

`application-path-map.md` 中的祖先提交清单只是历史线索，并非因果结论。
`df40880` 修改生产 `run_stack_3d_stages` 报告；本测试的旧 `core.evaluators.evaluate_3d` 直接调用 LTNE，随后用 `sum(h_vB*(Ts-Tb)*cell_vol)` 计算 Q，不经过该报告路径。
同样，`ee14cbd` 的模型焓分支需要 model_mass/model_fluids 输入；该筛选调用未传入，不能直接归因于模型焓启用。
仅影响能量的修改也不能单独解释两项 2D dP 变化。`a9da65f` 的新增入口参数是否通过默认内核路径影响这些案例须另外核实。

独立审查另确认 `fd2e001` 是 `5adb61d` 的祖先。后者改变了实际可达的 `solve_full_domain_3d` / `_gs_full_chunk_3d_staggered`：入口钉温、出口拷贝的端层处理改为完整端部控制体。因此它是 3D 热量差异的较强机制候选，但没有逐提交受控运行就不能给出其贡献比例或宣称根因已关闭。

## 建议独立跟踪的工作，不是解除门槛

1. **两项 2D 微小漂移追溯**：一组工作、两行验收。核对各自锁定值采集提交、输入、锁、默认参数和环境；用受控版本比较定位 Q/dP 首次变化。若证明实现缺陷则修复；若证明基线适用性变化则提交新旧依据供审定，不静默改 pin 或放宽容差。
2. **两项 3D 热量大幅漂移追溯**：一组工作、两行验收。优先检查最后 3D pin 之后的可达端部 CV/共享数值变更，再分别核对非均匀分支；需要原生场、边界能量及压力证据，不能仅比较最终 Q。
3. **3D 筛选预算与工程验证**：保留 max_outer=2 的原始回归输入及未收敛结果。另行定义工程验证所需预算/收敛与能量条件，获得明确范围后验证；加大预算的结果不得覆盖原两项失败。
4. **M-A 应用迁移验收**：继续检查准备数组、求解消费、FieldResult 独立后处理、W/W-m 转换、拒绝/未收敛状态与原生退出传播。用户已允许同源等价用于这一层；若这里发现差异，直接修复当前三模块实现，不能转移到历史问题。

四项旧失败、历史 NaN/缺退出证据仍保留；这些并不是四个冻结失败各自的诊断标签。本次四组已记录目标值均为有限数。后续补充的退出 0/2 与原历史记录分列。

上述分组可以组织排查，但整体 B40 门槛、Z00 收口和最终 M-A 声明仍未解除。独立只读审查 `b40_review` 核对了旧输入、锁定值历史、实际调用路径及迁移证据，同意四项根因尚未定位，并指出上述生产报告路径归因风险。本次审查仅覆盖此 B40 分析，不代表 PR #7 全部代码已审查。
