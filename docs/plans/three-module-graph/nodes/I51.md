## 任务

1. 公布真实可用的三个独立入口，维度与模型选择通过能力表校验。未实现后端不能出现在可用能力中。
2. ComputePipeline 只顺序调用三模块，保持已使用的 progress/cancel/ComputeResult 对外映射，不再持有另一套物理流程。
3. 接口不得默认绑定到测试替身，也不得调用旧完整 Pipeline 形成递归或重复计算。

## 验收

- 公共脚本真实运行且保持物理/状态意义；切换不支持的后端会明确失败。
- 既有 Pipeline 使用者无需为了已支持能力直接修改模块内部。
