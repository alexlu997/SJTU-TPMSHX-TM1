# Q10｜契约样例、独立性测试框架与导入规则

状态：planned。该文件是任务卡，不是完成证据。

里程碑范围：architecture。
依赖：G10。
分支：`codex/tm1/q10`。
状态记录：`state/Q10.json`。

## 任务

1. 建立人工构造的 CaseData/FieldResult/PerformanceResult 样例，含正反方向、部分开口、二维单位深度、三温与无效结果。
2. 建立边界测试：禁止私有跨模块导入、禁止上游对象序列化、禁止后处理调用求解、不可变性与同名不同单位检测。
3. 测试替身只位于 tests；允许其他叶节点复用人工样例以独立开发，不把它们描述为真实求解结果。
4. 为真实子进程验证提供测试工具，不制造因真实实现尚不存在而自动通过的测试。

## 验收

- 测试框架能检测故意构造的非法依赖和不完整数据；误报的合法共享模型依赖有明确规则。
- 禁止导入测试与后续最小依赖运行测试分开，不能靠 grep 一项宣称独立性。

## 必需证据

- 人工样例来源声明、测试日志、依赖规则表

证据必须写明代码提交、输入/数据版本、环境、命令、通过/失败/跳过数量、测试层级及未运行原因。测试替身通过只说明契约层通过；真实集成另有节点。
