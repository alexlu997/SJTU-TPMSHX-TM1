# SJTU-TPMSHX-TM1 架构

[中文](architecture.zh-CN.md) | [English](architecture.md)

集成原生 full-compute CC 候选通过严格 model-h 驱动使用既有空气／水积分焓 h(T)。它替代早期可变 cp 的 m*cp*T 适配器；该候选失败仍保留在历史记录中。此前数值和资源资格归属于各自构建。最终共享行编译策略要求完成受影响的数值／资源检查和应用验收。固定系数 Quick Design／独立温度、保留的 true-h CC 预热和单 A 侧 sCO2，以及交错研究路线，各有独立契约。

守恒交错温度输运在 Python 和 C++ 中使用相同的端单元 SOU 重构。靠近域端的内面使用两个可用的单侧斜率，并按物理距离进行 minmod 限制。外面保留给定边界处理；少于三个单元的轴保持一阶。产品 model-h 和非守恒研究格式保留独立重构契约。

工程后端一致性要求使用同一准备态 Case，并各自通过收敛与能量门。热负荷、压降和质量流量的相对差不超过 0.1%；出口与全场温度绝对差不超过 0.01 K。`test_backend_engineering_parity.py` 覆盖二维和三维的八种流体配对。完整迭代比较使用这些限制；中间场相对容差为 0.01%，近零残差比另设明确绝对容差。

实际迭代数和舍入裁剪次数可因后端不同，但每个次数必须符合本次预算、记录和停止原因。形状、状态、来源及物理门保持独立断言。极值位置可以不同，但仍必须标识原观测场中的真实极值。保存／重放、独立公式和组装检查保留更严格容差。这些比较不扩展到不支持的指标或未测物理条件。

接近收敛时，SIMPLE 动量残差在出口闭合和原 F2 门后，依据本次返回场独立审计。历史记录保留真实原始分子、分母和归一化残差。限预算二维求解保留最后闭合前观测，不新增证据。完整二维 SIMPLE 质量历史比较采用 1e-8 无量纲绝对下限，即默认 1e-6 F2 质量门的 1%。最终质量与 F2 检查保持原门槛。进度样本必须等于本次自己的已记录残差。

限预算外循环仍为未收敛。返回热状态使用其实际最后输入和原能量门检查，不能作为收敛的工程精度结果接受。完整驱动捕获和组件 ABI 测试检查某算法的场、迭代数和残差时，以当前热组件为准，不要求保留的 Python 热迭代器沿相同轨迹。公共工程一致性测试仍独立运行两个完整后端。fullCC 捕获对照组件积分 h(T) 边界功率账本，与保留的 Python cp*T 报告分开。

本文是仓库当前架构和物理契约。历史审计与报告说明演变过程，但不能覆盖运行代码或本文。

## 各路线的结果资格

执行完成、求解收敛、指标可用性和优化资格是不同状态。`run_case` 记录原生收敛结论；`evaluate` 判断各指标是否有充分记录证据。可用指标不是实验精度证书。

| 路线 | 原生收敛与最终证据 | 额外使用方要求 |
| --- | --- | --- |
| 二维 model-h | SIMPLE、外耦合、主／细热收敛和能量证据、Richardson 资格及压力包络。 | 多工况批次要求两套物理边界账本和既有主／细网格门；Q 为 W/m，总流量研究需显式深度。 |
| 三维 model-h | 最终 SIMPLE 检查、热／外收敛、有限场和压力包络；无源热阶段还需既有严格能量门。 | 多工况批次独立检查存档 `compute_phase2a` 的全局／逐格、源及边界证据，包括加入能量收尾前生成的结果。 |
| 二维／三维 true-h | 原生焓求解及最终状态方程／边界预算、物性检查；热证据在失败的最终更新前捕获。 | 检查该路线 `true_h_balance` 和收敛细节；不属于空气／水 model-h 优化器契约。 |
| 原生 full-compute CC（G5 候选） | 在接受的热质量面上使用严格 model-h；真实积分 h(T_face) 平流功率、Fourier 功率和相残差；完整边界误差比不超过 1e-7。 | 声明 `model_enthalpy_temperature_v1` 后支持已捕获热量：二维 W/m、真实三维 W。请求的 temperature 路线仍不同于产品 model-h 优化资格。 |
| 其他 temperature 与低层研究路线 | 各路线原停止规则、系数采样和记录状态。 | 固定系数热容输运、交错／MAC 研究和保留的单 A 侧 sCO2 不继承 fullCC 积分焓资格；历史文件保持原归约。 |
| Quick Design | 显式给定流量近似模式。 | 指标和可行性检查不证明完整 SIMPLE 求解。 |

GUI 和 CLI 保留原生收敛含义。GUI 失败或取消时保留此前接受结果。批量优化拒绝失败成员或能量门，并保留失败行。保存回读保留证据和状态，不提升未合格结果。

水 model-h 的首次热阶段至多执行一个既有 250-sweep 区间，然后交给流动更新。如果该初始试探超出液态水范围，则从不变的有效输入出发，将区间减半重试，仍受原热预算限制。非有限状态、后续相态违规和无效最终压力仍按原检查失败。

二维 model-h 的热负荷和温度变化稳定后，触发真实非线性 A/B/固体单元平衡及既有全局能量检查。各流体最大单元残差按自身积分交换量除以单元数归一化，交换量下限为 1 W/m；固体使用较大侧交换量。三个比值都必须不超过 1%。该平均单元负荷尺度不代表任意局部网格细化下不变。失败时在原预算内继续。最后热阶段未收敛时，外场稳定不能终止外循环。

主／细 full-compute model-h 均使用既有 Anderson GS 加速，包括没有额外端口细化的网格。试探 sweep 计入同一预算，并必须降低 GS 更新残差。最终接受仍需独立真实状态方程证据。

无源三维 model-h 的热负荷和温度变化稳定后，触发共享能量证据。残差或源平衡失败时，在既有预算内继续热 sweep。物理流入数据缺失时返回未收敛热阶段，供流动更新；增加 sweep 无法修复固定质量面。未收敛热阶段不能让外循环以收敛结束。最终证据复用，不另做数值求解。制造源测试保留原停止规则，因为其外源不服从无源 LTNE 交换平衡。

独立物理范围见[能力](capabilities.md)、[模型适用范围](model-resources.md)和[数据来源](data-catalog.md)。

## 运行流程

```text
applications -> preprocess.api -> CaseData -> solvers.api -> FieldResult
                                                          -> postprocess.api -> PerformanceResult
                         domain / models / versioned resources / file I/O
```

- `domain/` 负责不可变 CaseData、FieldResult、指标定义和运行控制端口，不依赖 Qt。
- `preprocess/` 负责物理网格／边界准备、固定几何和系数、模型／资源选择，以及可移植执行输入。
- `solvers/backends/python/` 负责准备态数值执行、当前状态物性评估和原生结果捕获。SIMPLE/LTNE 核仍在 `solvers/`。该层不导入前处理或正式后处理。导入公共求解 API 不初始化 Numba；加载 Python 数值核或显式线程控制时应用一次线程环境，后续运行保留调用方／工作线程掩码。二维循环直接读准备态物性，通过 `RunControl` 报告，并随原生结果返回应用系数和分区统计。不存在模仿窗口的运行时适配器或属性写入钩子。Python 外循环／C++ sweep 混合路线已退役；Python 使用原 Numba 核。保存态显式混合请求在 SIMPLE 前失败。完整原生执行由 `RunControl` 独立选择。
- `solvers/backends/cpp/` 通过显式 `RunControl(backend='cpp', native_library=...)` 提供独立准备态 Quick Design 和 full 2D/3D。主机库路径不存入 CaseData。共享 QD 校验和结果映射位于 `solvers/backends/quick_design.py`；物性阶段、液态水约束和热迭代由 C++ 驱动负责。返回的标量阶段证据扩展为相同场和警告记录，供后处理使用。full 2D/3D 在 C++ 中负责 SIMPLE、压力参考、外物性／热耦合和最终证据；二维还负责 Richardson 细化。绑定打包准备态数组并映射原生证据到同一 FieldResult，不调用 Python 数值核。full 2D ABI 2 保留原准备态 Nu 几何比，不在单位转换后重建。Python 仍为默认。必需原生 CI 已在 macOS arm64/Python 3.13 和 Windows x64/Python 3.12、3.13 通过。可见桌面与完整性能资格保持独立。
- C++ 固定流动 `solve_enthalpy` 另有显式 `temperature_fou` 和 `temperature_sou` 候选。两者以温度为非线性未知量求解守恒焓输运，使用带检查的 HEOS PT 更新、Fourier 导热和 LTNE 交换。`conservative_energy` 负责冻结有限体积 sweep 和直接焓面重构；驱动负责 EOS 刷新、停止和真实状态证据。候选要求声明标量入口并采用绝热外边界。SOU 出口重构与 model-h 不同。两者要求最大温度更新 K 门和两项显式能量门。普通 PT 状态非法时直接失败，不裁剪。SOU recipe 2 在普通 PT 评估前提出六样本 Anderson 更新；仅接受真实 PT／审计评价改善，拒绝时保留普通路径。只有完整普通块可以收敛或提供最终预算证据。原 H 算法仍默认。完整 C++ 二维／三维可在既有双流体 true-h 路线显式选择候选。持久化 `SolverConfig.enthalpy_algorithm` 和 `enthalpy_temperature_tol_K` 决定算法及更新门；不兼容路线在流动执行前失败。Python 方法和生产流体范围不变。增量 full2D v3/full3D v2 复用原结果布局和释放函数。只读查询提供实际算法、真实热导率和六个向外焓功率面。同一二进制的 recipe 查询根据实际算法标识 FOU1/SOU2，绑定复制到主、外循环和边界证据。缺少查询能力时在守恒流动执行前失败。离线读取支持保存态 SOU1/SOU2，并拒绝不支持的算法／版本配对；recipe 不改变 POD 或 ABI。可移植候选使用 `thermal_mode=conservative_energy`，各面功率负和为热量，二维 W/m、三维 W。离线校验证据，不重构 SOU 或调用 EOS。热质量／温度证据与后续最终流动更新分开，包括限预算返回。
- 原生 CC/QD、交错 temperature、model-h 和 conservative-energy 共用有限体积行，但保留物理模型及调用方的面准备职责。空气／水 full2D CC 主／细及 full3D CC Nz=1 调用严格 `solve_model_h_2d`；Nz>1 调用严格 `solve_model_h_3d`。它们使用接受的热状态 SIMPLE 质量面、既有空气／水 h(T)，并保留准备态 K/h_v。二维／Nz=1 为 A-SOU/B-FOU，Nz>1 两侧 SOU。增量 `get_model_enthalpy_evidence_v1` 在后续流动／物性更新和释放前捕获该热状态。可移植 `model_enthalpy_temperature_v1` 记录 h(T) 系数、求解相、残差、源／储库和向外平流／Fourier 平面；二维主／细身份分开，不使用旧热容账本布局。新字段缺声明时无效；不含新账本的历史文件保留原归约。真实三维 Nz=1 将质量除以深度交给二维，再将积分功率乘深度一次；温度不缩放。fullCC 不支持非零源，给定 B 为外部储库，不提供 B 求解证据。QD／独立 CC 保留固定系数热容输运。full3D true-h CC 预热在 Nz=1，以及 Nz>1 且 conservative=false、force_cell_centered=true 时保留私有 G4 核。两次 sweep 先求解两侧，再运行所选焓算法及物性／守恒门。单 A sCO2 使用同一私有核、给定 B 和原预算。这些保留行与交错／MAC 投影／热容研究契约不继承 fullCC 资格。迭代、不完整边界和构建要求见[原生使用方契约](cpp-migration.zh-CN.md#shared-finite-volume-temperature-consumers)。
- `postprocess/` 归约记录的场、通量和压力，不重跑求解器或访问私有运行时对象补证据。完整计算评估只在本次调用内，按侧别和主／细证据延迟复用已成功的热与质量归约。每个请求指标仍单独处理缺失、不支持和无效状态。
- `models/` 和 `df_surrogate/` 负责共享纯闭合和带版本资源。显式清洗／标定位于 `preprocess/offline/`。
- `io/` 负责严格 YAML/HDF5/JSON 交换。`cli_options` 将共享主机参数映射为 RunControl，不把主机路径写入工况／配置，也不让 CLI 使用方依赖工作流。VTK 导出是记录数据的后处理视图，不是新数值状态。
- `configs/` 负责随包工况配置。
- `pipelines/` 保留显式脚本阶段入口。调用方直接导入共享模型和数值后端，不使用 `sys.modules` 别名或导入时向后端注入函数。字典三维入口为 `run_stack_3d._run_3d_stack`。研究与守恒工具仍用它处理 ComputeConfig 范围外的单流体和制造源；它共享准备态后端，不另存求解器。这不是在等效公共契约建立前可删除的兼容别名。该入口和 `_build_3d_problem` 接受仅关键字 `control=RunControl(...)`，转发给初始 SIMPLE 和外耦合。cfg 中的 `_cancel_check`、`_progress_cb`、`_iter_cb` 以迁移错误拒绝。分别使用 `RunControl.cancel_check`、`.progress`、`.outer_iteration(current, total)`；`.iteration(message)` 是独立文本回调。不带控制的既有调用仍有效。原 `stages_2d`、`stages_3d`、`_stage_common` 导入门面已退役，前处理和助手从所属模块导入。原 `solvers.envelope`、`solvers.roughness` 门面也已退役。网格与投影助手来自 `models.grid`、`models.df_projection`。正式压力归约在后处理中使用记录的物理端口面。
- `controllers/compute_pipeline.py` 编排公共模块；模块适配器映射到历史 GUI ComputeResult 契约，是唯一生产结果映射器。旧二维／三维映射仅作为真实原生结果集成比较的冻结测试参考保留。
- `ui/` 仅负责 PySide6 和 PyVista 展示。两维结果缓存均用 ComputeResult。二维发布标量、元数据、警告和导出状态快照，同时共享场数组；三维保留已发布对象。失败或取消保留上次接受结果用于显示／导出，与当前草稿输入独立。画布工作台复用左侧几何／边界／求解控件。相位和三维 z 切片读取接受结果快照，草稿编辑不替换来源。图像导出遵循当前视图；CSV 保留摘要。三维 NPZ 保留完整物理 XYZ 显示温度（K）、两侧速度分量及模（m/s）、显示压力 `P_fA/P_fB`（Pa）、`L_mm/t_mm`（mm）和 `dx/dy/dz`（m）。旧 `vmag/P_kPa` 为 A 侧模和 kPa 压力别名。显示压力参考不变；完整原生热状态和通量属于 results.h5。`ui/typography.py` 为 Qt 使用系统无衬线字体，为 Matplotlib/VTK 保留出版字体，不捆绑字体或向低层导入 Qt。普通 GUI 计算捕获启动线程 Numba 掩码，在复用 Qt worker 中应用／恢复；优化保留独立进程／线程策略。桌面入口在开口内用均匀速度，开启局部密度热输运，不额外六壁面细化；端口／壁面细化通过网格方案选择。载入不同退役设置的预设／会话时报告转换并保存当前显式值；脚本设置另行管理。
- `validation/` 和 `runs/` 是可执行研究与验证工具，不是替代生产实现。

实验 Q 运行器 `validation.cases.validate_sco2_exp_q` 在首次求解前冻结所有拓扑／工况／维度成员。CLI 每完成一个成员，通过既有同目录暂存发布器写 `partial.csv` 和 `state.json`。失败、取消和数值未合格成员均保留；执行完成与 Q 验收分开。状态保留此前尝试及精确 CSV 记录，避免不匹配或不完整文件对静默供给续跑结果。发布器仍受单写入者和 Python 异常恢复边界限制。

`--out-dir` 要求新目录或空目录，默认在 `.cache/validation` 下新建。`--csv` 仍是可选最终摘要导出。继续时重复原选择和 `--csv` 参数，用指向原目录的 `--resume-run` 替换 `--out-dir`。续跑要求相同、干净且可识别的代码、实际 Python／依赖版本、模型环境、设置、完整成员清单和精确参考数据快照。未经验证的外部数据修订仍标记未验证。存储的输入快照只证明实际使用输入相同。仅跳过已完成且数值／参考合格的成员，其余重跑。最终 Q 结论使用原分母和阈值。不带 `checkpoint_dir` 的程序化 `run()` 保留内存接口，不创建文件。取消保留证据，CLI 返回 130。

GUI 入口为 `python -m sjtu_tpmshx.main`，源码无界面工作为 `python -m sjtu_tpmshx.cli`。优化和设计使用同一公共契约及明确命名近似模式。macOS 文件夹启动器向同一 GUI 传 backend=cpp、`native/lib/macos-arm64/` 随附库和项目表目录。Python 保留 UI、准备态输入组装、优化编排和结果处理。显式原生选择不改变公共默认或研究专用 Python 路线；旧数值实现仅在各自替代门通过后退役。矩形二维／三维 M-A 评审、CI 和合并主线验收保留在[固定历史](history/README.md)。M-B 扩展及未满足条件见[能力](capabilities.md)；历史基线失败保持原状态。

生产域当前仅支持二维／三维 **Rectangle**。桌面显示固定矩形／长方体标签，不提供多边形控件。旧多边形预设在改变输入或结果前拒绝；启动会话不恢复并明确提示。矩形文件仍受支持，显式保存形状索引 0。历史 `ui/polygon_calc.py`、多边形核和三角网格已退役，原代码见[历史索引](history/retired-tools.md)。重开多边形计算须实现主线物理规则和真实 CaseData/FieldResult/PerformanceResult 交接，不只是移动 GUI 代码。

二维动量求解器使用 SIMPLE。实验 SIMPLER 已退役，原基准和负面结果保留在历史索引。B 侧局部开口实验也已退役，包括 M4 面积缩放、逐格参与掩码、温度冻结和 H2 出口导热抑制。显式旧设置在执行前拒绝，包括研究字典和直接准备态输入。真实端口位置、尺寸、方向及质量／能量检查继续有效。默认模型不加额外 B 侧参与修正。独立 `TPMSHX_SCO2_COMPRESSIBLE` A 侧压力／物性实验保持区分，不是 GUI 局部密度热输运设置。历史实验及原结果见[退役工具](history/retired-tools.md)；在当前模型重跑原几何属于新比较，不是原实验的复现。

历史水 Nu 比较和旧全面二维焓参考位于 `tests/water_nu_reference.py` 和 `tests/enthalpy_2d_reference.py`。生产保留直接水 CFD 闭合和共享三维焓适配器。无使用方的 `postprocess.report` 和 `postprocess.visualization` 已退役；公共评估、记录场绘图和导出仍受支持。

<a id="shared-solver-implementation"></a>

### 共享求解实现

所有受支持流体在二维使用 `SIMPLESolver`，三维使用 `SIMPLESolver3D`。`solvers/_solve_common.py` 负责 F2 配置和公共收敛监视：动量、新密度局部／全局质量及出口回流必须连续通过。完整计算与直接求解调用使用同一标准。`convergence_mode=None` 解析为 `f2`，显式 `legacy` 被拒绝。静态场只触发检查，不能单独证明收敛。仅质量／速度退出及内部 SIMPLE Anderson 已退役；热与外耦合 Anderson 继续使用。

三维返回路径在最后密度更新后再次闭合出口通量，并在返回态重测四项门，局部质量包含压力固定的出口单元。临时 `tol` 未通过最终证据时，清除连续通过计数并在原预算内继续。下一普通迭代先测包含出口闭合的速度变化，再执行既有停滞规则。最终步证据拒绝标记为 `post_closure`；停滞或预算耗尽仍为失败。

动量面使用连续方程在交错控制体面上积分的有符号质量通量。横向黏性面将两个半格条带相加，各用自身串联黏性阻力计算。既有控制体孔隙率除法和 D-F 阻力约定保持。质量亏损迭代在预测方程两侧加入同一延迟对角项，在不动点抵消，且不计入物理 F2 残差。压力修正使用真实预测对角元。

活动 SOU 限制器还在固定面质量的单调模板上，用真实网格距离限制局部源项负导数；这不是对完整非线性 Jacobian 的界限。该项防止拉伸网格两次 sweep 振荡，也在不动点抵消，不改变请求松弛或 F2 容差。

`tol_simple`、SIMPLE 的 `solve(tol=...)` 和 `TPMSHX_SIMPLE_TOL` 已退役，因为它们不设置 F2 容差。旧文件导入显式提示并丢弃 `solver.tol_simple` 和 `optimizer.tol_simple`；新配置不保存。各 F2 门使用 `mom_tol`、`mass_local_tol`、`mass_global_tol`。压力子问题残差历史仍保留原定义，供自适应 AMG 使用。运行时间／精度比较必须匹配实际输入、近似模式、网格、预算和 F2 设置。

粗网格初始化提供有界初值，不提供收敛证书。正式 full 3D 默认关闭。显式开启时使用配置的首粗层上限；独立调用中的 `None` 保留现有单元数选择，即 `_AMG_GATE`，当前为 2000。各粗求解器保留自动递归选择和 200 步子层上限。这是逐层限制，不是共享 200 步预算。半网格各轴最小四单元、热启动跳过和细网格压力边界恢复不变。

两个完整后端按侧保存 `diagnostics.coarse_bootstrap_trace`。它记录有效策略、阈值、首层／递归上限、尝试形状、深度、逐层实际停止、计费迭代和种子应用。`solve_started` 表示该层至少进入一次迭代；`actual_levels` 统计这些层，`started_cap_sum` 只求和这些层上限。`total_charged_iterations` 统计已进入迭代，包括失败的一次。跳过层或子层运行时已取消的父层，可以保留配置上限但计费为零。记录不控制或延长求解。旧初始化摘要仍描述第一粗层。旧结果可读；重跑显式 legacy 配置必须选择 F2，并接受独立测量的新结果。

交错 Python 能量投影的 `_LAPLACIAN_AMG_CACHE` 属于 Python 后端进程，按网格形状索引。它保留图算子和 AMG 层级，不保存工况场或右端。PyAMG 可在首次使用时延迟构造粗层伪逆。相应 Python 能力退役时，其正式使用方一并退出生产。保留的研究／MMS 使用方具有显式进程／重置生命周期：生产不调用重置钩子；研究重置须等待活动使用方结束。清缓存不证明分配器已把内存页归还系统。该所有权不引入 LRU，也不要求每工况重建层级。

两个后端消费 `models/fluid_props.FluidModel`。注册表直接从 `tpms_props` 导入空气／水基础函数，从 `nu_correlations` 导入 Nu。`tpms_calc` 保留公共重导出，注册表不反向依赖它。关联式、物性来源和适用校验留在所属模型。共享外迭代和温差跟踪位于 `coupling_skeleton.py`；完整两维均跟踪 Ta、Tb、Ts，二维另保留密度门。维度专属求解顺序和原生通量捕获保持显式。

二维 SIMPLE 构造器消费准备态分区阻力数组，旧 `zone_config` 行预测已退役。`P_ref` 后参数仅能按关键字传入，避免旧位置分区参数被静默重解释。残差回调异常通过完整计算原样传播，不是可以忽略的 UI 通知。

完整二维／三维前处理接受 `zones.axis="continuous"`，其 JSON `config` 包含 `x_decision`（先 L 控制量、后 t 控制量，单位 mm）、`n_ctrl_x`、`n_ctrl_y`、`symmetric_y`、`spline_order`、`L_bounds`、`t_bounds`。主几何负责拓扑、材料和域尺寸。二维控制描述 L(x,y)/t(x,y)；加入 `n_ctrl_z` 表示真实 L(x,y,z)/t(x,y,z)，二维后端拒绝它。

样条在最终物理单元中心采样，包括非均匀网格，不量化，也不使用离散分区高斯滤波。三维历史 XY 控制仍表示沿 z 拉伸。CaseData 保存原控制量及 SI 场，执行消费场。两侧都在各自 SIMPLE 坐标保留完整局部 K/cF。既有三维网格分区也遵守此规则：A 不再横向平均阻力，B 不再替换为均匀阻力。因此旧非均匀网格分区重算可能改变结果，保存的历史结果不改写。

三维构造器也接受行数组并沿第一轴广播。既有动量采样保持：u 面平均相邻 x 单元，v/w 面取下游单元。几何梯度仍需独立物理验证，参数平滑不能证明 TPMS 曲面连通或可制造。连续场要求对称通道。

Shanghai Gyroid air-A/water-B 的 `df_mode="experimental"` 也支持连续场，但保留原 7/0.6 mm 参考几何和试验域。冻结均匀 HX 因子逐格应用于局部 CFD K/cF，基准与候选使用同一因子。元数据标记 `continuous-field-extrapolation`，仅作探索趋势，不代表梯度精度。显式迁移还允许固定质量流量下孔隙率变化使入口速度离开旧均匀 HX 窗口；原窗口和外推状态仍记录。均匀标定请求保留速度范围。其他空间标定限制及 sCO2 空间限制不变。

`optimization.multi_condition.prepare_fixed_mass_flow_case` 先准备候选，再按给定总质量流量计算各入口速度，最后重新准备正式 Case。分母为入口密度乘以开口上“局部单通道孔隙率 × 真实归一化入口速度轮廓”的积分。二维渐变轮廓按几何开口面积归一化，与空间孔隙率场独立，严格匹配 SIMPLE 边界。快照保存候选正确速度。二维总质量流量研究必须提供物理深度，原生结果仍为单位深度。

`preprocess.api.prepare_inlet_mass_capacities` 复用原生几何、网格和端口构造，不评估速度相关闭合。静态输入校验不使工况可执行；解析速度仍须完整配置与 Case 前处理校验。普通前处理保留相同完整检查。导入流量优化记录已解析均匀参考配置用于重放；各候选根据局部孔隙率重新计算速度。

`aggregate_multi_condition` 将有效水侧吸热 `-Q_B` 和双侧相对压降与配对基准比较。它要求完整收敛结果，热与压力目标分开。各工况等权，两压力侧各占 50%。这些助手不验证闭合，也不启动优化。

`evaluate_condition_batch` 将固定设计的 air-A/water-B 工况串行运行到新目录。每个阶段成功后立即保留其输入、准备态 Case、原生结果和指标。`batch.json` 保存全部请求成员、失败阶段／原因、取消后未运行成员，以及基准指标值／定义和来源 ID。取消向上传播；普通工况失败继续，不虚构惩罚值。

若失败／取消检查点保存也失败，则传播原异常，并附上保存错误说明；已有文件仅是最后成功证据，不是完整最终存档。没有活动异常时的保存错误仍为错误。桌面展示这些说明，不将过期 running 检查点显示为取消结果。基准比较检查均匀参考、配对工况、端口、模型、D-F 模式、冻结运行覆盖、已解析粗糙度、总流量、网格和求解设置。原始工况必须共享几何与数值设置。

只有完整数值合格批次可以发布两个目标。除原生收敛外，三维复用 `postprocess.conservation.compute_phase2a` 完整控制体证据：各流体全局／cellmax 残差和 LTNE 源不平衡均低于 1%，且物理边界账本完整。原生三维收尾与守恒审计使用同一纯函数，由 `result_math` 所有，并经现有后处理入口重导出。二维要求原生主／细 model-h 平衡、完整物理边界及 Richardson 接受。

这与实验精度、正式对流 `energy_imbalance_rel` 和梯度适用性不同；物理预测仍需后者证据，但不禁止明确标注、使用冻结参考修正的探索搜索。

`optimization.multi_condition_optimizer.run_multi_condition_optimization` 以相同随机初始设计和评估预算比较 qLogNEHVI、qLogNParEGO、Sobol。只拟合完整接受批次，最大化 `(heat_gain_percent, -pressure_ratio)`，保存完整决策向量、场定义、工况、失败和原生批次路径。BO 依赖可选，在物理评估前检查。桌面继承当前 ComputeConfig，接受固定质量流量表，并不经平均恢复完整选择场。有限预算 Pareto 集是模型趋势；最终候选须全工况与网格检查，并据新结果重算目标。nTop CSV API 以可往返浮点精度导出 XY/XYZ 坐标和完整控制来源。

三维外循环持有一个活动 `_OuterState`，迭代后直接返回，不维护第二套同步状态。每步准备局部换热／输运，求解 temperature/model-h 或 true-h 热启动与焓，分离原生热证据，再记录诊断并检查收敛。未收敛 post 依次刷新 A 流动、热物性、B 流动；保留 A/B 不同温度／物性顺序。model-h 质量面在温度面平衡前捕获；true-h 独立平衡并投影质量输运。逐调用输入不变为持久迭代状态。原生热快照与 post 更新的导热率、热容和最终 SIMPLE 数组分离。

迭代标签、三维进度和 SIMPLE 上限日志使用本次实际限制。三维默认外预算 12，`fast_sweep` 为 3；进度标识进入迭代，不是耗时比例或收敛证明。应用流水线为准备和发布保留独立进度区间，在必需阶段返回后才报告完成。

三维初始 A/B SIMPLE 只用一级并行。任一侧达到既有并行 sweep 网格阈值时，两侧在调用线程依次运行，各保留并行 sweep。否则两侧分别在线程中运行串行 sweep。所有受支持流体共享此规则，避免并发启动 Numba workqueue；外循环物性刷新本已按侧顺序。线程数和数值门与调度决定独立。可选动量 SOU 使用串行 sweep，因为距离二模板读取同红黑色单元，活动场并行不安全。FOU 保留原并行阈值，热 SOU 调度另行管理。

二维持有一个活动 `_OuterState2D`。流动步骤重建两个 SIMPLE 对象，并等待两个 worker 结束后传播失败。随后准备热输入、求解能量路线、校验返回、刷新物性和检查收敛。致命流动分类使用本次 SIMPLE 消费的温度。post 重新绑定四个密度／热容场。即使最终 post 执行，Richardson 仍保留最后主热调用输入。逐调用热输入借用数组，显示平滑与原证据分开。非有限热返回在物性刷新或捕获前失败。不可达的 NaN→入口替换、`energy_nan_hit` 状态和新结果诊断已退役。旧诊断字典仍可读，不改历史值。true-h 热负荷来自记录的质量／焓面通量；旧标量压力 h(T) 选项仅作独立测试参考。

热路线按当前资格条件选择：

| 路线 | 共享实现与保留差异 |
| --- | --- |
| 真实焓 | 含 sCO2 配对采用有符号质量／焓输运；二维适配器调用共享三维焓核。full3D CC 在所选焓求解前使用保留的 G4 两次预热 sweep。原分区／路线限制保持。 |

sCO2 限制针对几何组合，不针对另一流体。sCO2／水、sCO2／空气、sCO2／sCO2 均可使用 true-h，任一侧均可为 A/B。任一流体是 sCO2 时，公共配置拒绝启用分区和非零等值面偏移。各流体仍须满足自身物性与关联式范围。

内部热面导通量使用两侧真实中心至面的串联热阻：`G = area / (distance_left/K_left + distance_right/K_right)`。SOU 在物理坐标限制梯度，从上游中心外推到共享面。拉伸网格上的半索引步不等于半物理单元宽度。sweep 和能量账本使用同一面定义，但仍需独立解析通量验证。

二维 GS 和红黑热核每个 chunk 只准备一次扩散导通量、体积加权流固交换和固体对角元。数组仅属于本次调用，下一个 chunk 可见系数变化。model-h 热容与延迟通量每次 sweep 刷新；单元顺序仍为 A、固体、B。model-h 行内联到严格数学核；仅该路线跳过无用的温度形式 SOU 工作，自身有符号 model-h SOU 重构仍活动。

temperature/model-h 停止比较两次观测热负荷，包括零负荷。近零相对变化分母以一个原生热量单位为下限：二维 W/m、三维 W。必须同时满足既有热量容差和温度稳定。零热量不能证明漂移温度场收敛。

真实焓流体扩散是基于温度的 Fourier 导热，并在各共享内面一致线性化到焓未知量。压力引起的焓差本身不是温度梯度。两个生产适配器都要求新的 HEOS 流体／固体方程残差：各相绝对单元残差和的最大值及边界能量不平衡，均不超过原生单位 `max(abs(Q_A), abs(Q_B), 1)` 的 0.001。焓更新门独立。最终 chunk 含裁剪时不能判收敛。true-h 账本记录有效设置、残差预算、裁剪次数和退出原因。

现有产品 model-h 在两维的两侧均用有符号质量面和 minmod SOU。流体 Picard 使用共享 `MODEL_H_RELAXATION=0.2`，包括出口单元；三维保留显式更小值。早期二维 B 侧一阶默认和三维按流体名选择松弛不适用此路线。阻尼改变迭代，不改变稳态能量方程。Q／场、物理边界能量、固体能量和质量检查分别保留原阈值。转弯流回归覆盖串行／红黑和物理 A/B 标签不变性。

无源三维 model-h 在热量／温度稳定后触发真实状态能量证据，只有通过才内收敛；失败继续原预算，缺流入则返回未收敛供流动更新。制造源保留独立停止规则。model-h 残差定义和预算不同于 true-h 的独立 0.001 方程门，不能从共同 `converged` 字段推断验收相同。

严格 fullCC 在 model-h 内具有独立停止和边界契约。二维主／细及三维 Nz=1 使用 A-SOU/B-FOU；Nz>1 两侧 SOU。身份分别为 `model_h_tface_sou_fou_strict_v3` 和 `model_h_tface_sou_sou_strict_v3`。面输运既有积分 h(T_face)，入口／出口单元按物理距离重构。严格入口 Fourier 使用行和审计共享的热阻／矩重构；非严格 model-h 原边界不变。

除 Q／场稳定外，还须新计算完整边界账本：最大相绝对单元残差和与耦合边界／源不平衡中的较大值，除以界面交换尺度后不超过 1e-7。尺度下限为一个原生功率单位。失败继续原预算；流入不可用不能判收敛。给定 B 有储库功率，没有 B 求解残差。严格路径支持既有 fullCC 非对称和三维水／水，不扩大非严格产品 model-h 或授予优化资格。

产品 model-h Richardson 细化上限为 12000 sweep，以便细网格满足门槛；fullCC temperature 角色的细化保留严格 h(T) 驱动和 5000-sweep 预算。见[空气／水收敛与验证记录](history/README.md#2026-09-18-历史材料整理)。

修改共享收敛规则会影响两维；修改某维动量或热核会影响使用该路线的全部流体。EOS 或 Nu 修改属于流体／模型所有者，不另建逐流体求解器。跨路线方法修改需要独立数值资格，见[实现与验证记录](history/README.md#2026-09-18-历史材料整理)。

<a id="persistent-interfaces-and-physical-state"></a>

### 持久化接口与物理状态

CaseData 包含实际准备网格、设计场、边界输入、固定热／流动几何、模型版本和已解析设置。配置快照是来源，不是接收方重建指令。进度／取消回调独立且不序列化。未知模式／资源或准备态不完整时失败。完整两维执行与文件交换采用同一物理网格检查：规范 XY/XYZ 轴序、SI 宽度、一致边缘。后端域长度和流向坐标仍是额外执行约束。

FieldResult 包含原生场位置／单位、原通量和压力证据、执行／收敛状态与诊断。显示压力／温度不替代原状态。诊断数组 NaN 和完成但未收敛运行保持可见；严格 JSON 指标以原因记录不可用值。取消／失败不返回虚构完成存档。

各完整后端显式生成显示／流动场与最终诊断，直接将诊断传入捕获，不按值类型猜测所有权。保留的三维字典入口仍返回扁平兼容映射，包括可选审计导出和缺场占位。最终报告诊断与最后热快照分开；报告参考不能替代正式原生证据归约。

完整二维热量为 W/m，不虚构厚度或 z 壁损失；完整三维在应用归一化前为 W。Quick Design 是给定流量 LTNE 加准备态解析入口压降，不是 SIMPLE。其离线指标无需 EOS 或标定调用。

完整热指标使用 `native_boundary_v1`：Q 为 A 侧主网格边界热损失绝对值，Q_A/Q_B 为有符号热损失，放热为正。能量不平衡用同一原生侧热量。出口温度按向外为正的有符号热质量通量加权原主热温度；质量流量报告热边界总流入。二维 Richardson 热量单独命名 `Q_richardson_A/B`，不替代主 Q，额外求解及物理／收敛检查继续生效。

完整压降采用 `pressure_face_v1`：最终 SIMPLE 压力外推到物理进出口面，再按几何开口面积加权。两维共享归约。空气入口校正也用这些面：迭代出口单元锚点，使入口开口面积均压与指定绝压相对误差不超过 `1e-4`。两维共享 `solvers/_solve_common.py` 的压力初始化和有界 P² 更新。

高于既有压力下限的正一维估计用作初始出口单元锚点；等温估计不可用时从指定入口压力开始。向下更新至多消耗当前到面／单元压力下限的剩余平方压力距离的一半，然后重算耦合流动。原提案、接受步长和初始化方法保留在入口状态的 `iterations`。这些数值选择不决定物理有效性。

入口检查加入外收敛门，校正默认开启。显式 `p_in_shooting=False`／`TPMSHX_P_IN_SHOOT=0` 仍为诊断覆盖，不能将不匹配入口判收敛。两维空气物性、热及报告场使用同一 SIMPLE 绝对状态，不再二次平移以固定入口单元行。数值／实验前后证据见[压力边界诊断](history/README.md#2026-09-18-历史材料整理)。

不可压路线在每次 SIMPLE 内冻结密度。三维水和默认 sCO₂ 保留入口压力密度／黏度约定；二维既有外刷新使用局部绝对场。两维不可压绝压参考均将物理入口面开口面积加权算术均压锚定到指定入口压力。热 EOS 和相态检查使用本轮绝对场。即使失败的最终 post 产生不同最终流动压力，最后热压力仍独立保留。后处理不在新状态重建热焓。压降保留最终 SIMPLE 定义和独立记录状态。

指标定义随 JSON 和 GUI 导出元数据保存。旧指标文件保留原定义；映射当前 GUI 前应重新评估其原生结果。冻结后端报告参考是历史软件数值参考，不是现行指标契约。`domain.metric_spec` 负责显式指标族、单位和完整计算定义版本。PerformanceResult 要求映射键匹配侧别 spec 名或指标族，JSON 同样检查。GUI 在给 Pa/K/热量字段赋值前检查所有消费定义及维度热单位。多工况聚合要求当前有符号热与压力定义，不能仅因两记录同样误标而接受。不兼容含义直接拒绝，不换算单位或修改历史文件。

`PartialBCConfig.uniform_inlet_2d` 选择几何重叠而不使用原四单元入口渐变。前处理记录轮廓，二维执行消费并校验同一轮廓。桌面两侧固定为 true，不提供轮廓开关；加载旧设置时报告转换。低层 API 保留 flag=false 的脚本历史轮廓。选择不改变总质量流量、端口几何或三维流动。

旧空气／空气筛选优化器、前处理、冻结 B 后端和指标归约已退役，[历史索引](history/retired-tools.md)保留源码与数值参考。当前多工况搜索使用完整前处理和执行。`models.continuous_field` 为该路径、预览和 nTop 保留 XY/XYZ 插值。保存决策必须按原边界、控制网格、对称性和样条阶数解码。几何窗为 L=4..8 mm、t=0.3..0.6 mm，不扩大 Nu 证据或证明梯度曲面连通。

历史筛选结果按原单位和状态可读，但现执行和指标评估拒绝旧模式。新配置不含 `optimizer`；`ComputeConfig.to_dict()`／`to_json()` 只在该段被显式提供或由旧存档加载时保留。工况快照和优化记录使用同一序列化。旧值仅供存档；当前优化求解预算来自 `ComputeConfig.solver`。候选数由独立 `n_init`、`n_iter`、`q_batch` 决定。历史 Pareto 几何导出仍要求原配置并保留失败状态。

完整计算分区也按物理单元中心准备。二维所有分区模式都按横向单元宽度权重和实际方向（含反转），将热 L/t 场投影到流动行。D-F 仍在平均 L/t 后评估。三维离散 XY 区按物理坐标选单元，保留覆盖与平滑规则，两侧动量均消费局部 D-F 数组。

快速尺寸设计仅在全部最终工况收敛、数值有限，并满足热量／温度和压降限制后接受候选。Q 要求的长度搜索使用返回热量，包括 mean 阶段；温降要求使用出口温度。显式 `solve_Lx(target=...)` 仍是 K 单位出口温度覆盖。入口 cp 温度估计只用于初选控制工况；独立最终冷启动决定可行性。

最终工况、GUI 和 Excel 保留冷热两侧热量及既有能量不平衡的值／可用性／原因。该诊断不参与可行性过滤，不可用不是零。设计物性在入口、代表 mean 状态、外部热启动和各 const/mean 阶段返回的每个水温单元上应用共享液态水约束。均使用声明入口压力，因为 Quick Design 不解局部压力场。

非法输入立即失败；非法试探场是不可接受尺寸样本，不虚构带符号求根残差。若端点超出水状态范围，有界冷搜索可找到内部液态候选。仅接受冷启动严格复核候选；搜索耗尽不证明物理不可行或样本间全局最小。解析压降含义不变。const/mean 的水 Nu 均用 320 K / 0.2 MPa 的 Pr。mean 更新其他水物性、Re 和体积换热导热率。`metadata.properties.Pr` 记录实际阶段状态，不是 Nu 代表 Pr。sCO2 参考 Pr 独立不变。

独立进程使用 case.yaml＋case.h5、results.h5、VTK 视图和 metrics.json。精确契约及模式限制见 `schemas/three_module_v1/`。最小后处理有独立锁和真实导入／运行检查；完整环境不能证明最小安装。并行警告与控制状态属于各次调用。跨契约数组与可变输入分离并不可变。仅改元数据可复用完整连续不可变 bytes 缓冲区，但用独立数组头；新数组形状或 dtype 改变不影响原数组。会保留较大父缓冲区的切片会复制为紧凑存储。

<a id="cooperative-cancellation"></a>

### 合作式取消

完整 Python 和 C++ 入口在准备执行输入或加载原生库前检查取消，主机选择校验仍适用。有效的预取消请求抛出 `CancelledError`，即使所选绝对库路径不存在。未取消且缺库的请求保留原错误。

流水线、求解器和 GUI 编排共享 `domain.cancellation.CancelledError`，它继承 InterruptedError，并由 `controllers.compute_pipeline` 和 `ComputeOrchestrator.CancelledError` 重导出。只有显式取消检查点抛出它；即使取消已请求，无关异常仍是错误。传播前等待两个 SIMPLE worker，真实失败优先于取消。编排器直接将此异常作为取消终态；GUI 适配器只绑定参数，保留原异常。

二维每次 SIMPLE 迭代和既有 LTNE chunk 边界检查，包括 Richardson 细化。三维保留每 25 次 SIMPLE 和 LTNE chunk 边界检查。共享 true-h 每次物性／sweep 迭代检查。原生线性求解、JIT、LTNE chunk（二维默认 500 sweep）或焓物性／sweep 必须完成后才到下一检查点。没有强制线程终止或固定墙钟取消时限。取消不发布结果。

<a id="ui-structure"></a>

### UI 结构

桌面偏好、会话／历史使用平台用户目录，不写安装包。`controllers/user_storage.py` 负责路径，只导入缺失的已知会话／输入文件并保留原件；外观只读当前用户配置目录。会话、预设／配置和工作区标记先写目标目录唯一临时文件，再原子替换。并发保存以最后成功替换为准；失败保留此前完整目标，只清理自己的临时文件。不合并并发编辑，也不提供跨文件事务。`desktop.py` 在加载 GUI 前配置可写缓存并提供安装入口；独立打包见[桌面说明](desktop.md)。

现有会话恢复完整输入，包括流体、方向、网格和端口，不重新套预设。上海默认仅适用于无会话新工作区或显式重置／载入。各工作区独立保存分区轴、表格和连续控制。旧会话缺少分区数据时清空并关闭；若原来开启则提示，不复用其他工作区分区。启动将温度转换为 K，物理值不变。

复制 Python 和可复现链接与保存输入共享完整 GUI 预设捕获／恢复，包括温标、分区、连续场和自定义模型。Python 片段要求已有 window，只恢复输入不求解。该预设不同于公共 ComputeConfig。

无包装 line_edits JSON 和旧平铺配置是部分导入。公共预设路径仅将给定字段合入当前捕获输入。显式温标切换对未提供入口温度作物理等值转换；省略模型、控制和优化工况保持。修改控件／缓存前，对合并输入做跨字段校验；维度或分区表布局不兼容则拒绝。带版本完整文件、预设库和启动会话仍遵循完整恢复／历史默认规则，部分导入不重定义它们。

- `ui/builders_canvas.py` 组装可见几何、结果和优化工作台。`build_canvas_area()` 只协调同文件具名构建器。
- `ui/mixins/tab_view.py` 负责可用性和路由，包括二维／三维结果切换，不以隐藏控件作为导航状态。
- `ui/panel_vis_3d.py` 负责 PyVista 展示。构造器把工具栏、控件、视口、状态和计时器交给专门方法，渲染仍留在同一控件类。

结果底栏和历史直接格式化已发布标量快照，没有隐藏结果标签、重复 chip 条或百分比差计算。草稿不替换接受结果及单位。只有最近发布结果拥有场缓存、摘要和导出。Pareto 图像可用性由自身画布决定，复制／导出无需单点场结果。菜单加载和 JSON 拖入共享当前／受支持旧 GUI 文件解码器。

失败或取消保留完整快照。发布后渲染失败保留新数值结果与来源，同时使不可用视图和旧图／探针内容失效。当前多工况优化器保留各维完整 ComputeConfig 求解设置；初始／后续设计数是搜索预算，不是收敛证书。求解器保留既有收敛和物理检查。外部 CLI 设置若无法在 GUI 控件表达，不能静默恢复成不同工况；交接明确拒绝不匹配。

<a id="physical-invariants"></a>

## 物理不变量

这些约束保护已有证据支持的求解行为。只有显式数值模型变更，并配套直接相关验证，才能修改。

1. **可压缩空气。** 空气采用理想气体密度路径，不能替换成常密度或等温捷径。
2. **孔隙率只分配一次。** 对称 LTNE 调用方传完整孔隙率，由能量求解器生成两个半孔隙率流体。偏移等值面由上游 `models/asym_split.py` 计算 eps_A/eps_B，两者和为总孔隙率，核不再减半。各侧有效导热率为 `K_ff_i = eps_i * k_i`。对称准备系数因此为 `eps_total/2 * k_i`；偏移因子 `2*split_i` 只应用一次。已有准备态文件保留冻结系数；重新准备原配置才能得到修正值，不改历史输入／结果。
3. **质量通量入口。** 可压缩空气在两维均用质量通量入口。求解器速度为孔隙速度，不是表观速度。
4. **Darcy–Forchheimer 归属。** `df_surrogate.predict_K_cF()` 是纯几何基底，全部流体和两侧共用一张水＋sCO2 CFD 表。K0/cF0 只依赖拓扑、L、t，在 4–8 mm × 0.3–0.6 mm 内双线性插值，与 Re 和流体无关。UI 只有两个生产模式：光滑壁 CFD 是通用 ComputeConfig 默认并兼容 V2；内置上海预设默认实验标定，保存输入保留选择，旧文件缺少选择项时保持 CFD。实验标定在流水线组装后、压力初始化／SIMPLE 前，各侧应用一次经审查的固定有效修正；求解期间 K/cF 固定。选择的数据集必须匹配试验批次、边界、压降定义和几何。它不能证明流体固有 D-F 物理差异。修正可能吸收测压点、缩扩口、集流／分配区、整机损失、流动面积／通道数定义、仪表零点和数据减缩；这些贡献未单独建模。没有同装置比较时不能归因于流体。旧 `gamma_df` 和 `rbf` 研究模式已退役，显式选择会报错。代码、表和结果见[历史索引](history/legacy-models.md)。
5. **Nusselt 归属。** 空气、水、sCO2 基础式位于 `models/nu_correlations.py`。唯一现行 sCO2 有效参数资源为 `configs/sco2_effective_nu.json`，由 `sco2_effective_nu_config()` 返回校验后的 Sco2NuConfig。保留字段 alpha_D/alpha_G 表示总 Ceff，在最终 Nu 下限前只乘当前基础式一次；没有额外 beta 或输出 Q 缩放。通用 cfd_smooth 默认和本次保存参数不变。显式选择才加载当前资源；旧 Case 重放记录值。退役实验 gamma 助手和环境开关不是第二条路线。证据见[模型资源](model-resources.md#sco2-有效-nu-系数)。完整两维通过 `models/local_heat_transfer.local_speed` 重算各侧局部标量 Re/Nu，速度为当前单元孔隙速度模 `sqrt(uc² + vc² [+ wc²])`。不得只取固定入口轴分量或再乘孔隙率。有符号法向分量仍负责质量／焓面通量。真正低速保留现有 Re/Nu 下限。入口范围观测保留，首次局部刷新前不再存冗余 bulk h_v。给定速度近似模式保留原定义。在转弯流中局部应用整体拟合标量 Nu 仍是模型假设，与速度一致性要求不同。见[实现与配对验证](history/README.md#2026-09-18-历史材料整理)。
6. **可压缩包络。** `models/envelope.py` 检查真实最终压力和局部 Mach。非有限状态、压力≤既有 1000 Pa 下限及 Mach≥1 仍无效。正压／亚声速场还须满足指定物理入口压力才可收敛。等温一维初值不可用只是启动数值问题，不证明耦合非等温问题无解。不得扩大裁剪或强制给答案来绕过最终场／入口门。
7. **压力参考。** 理想气体侧 P_ref_abs 锚定出口单元，局部绝压为 `P_ref_abs + P`。真实出口面外推表压可非零；`P_ref_abs + dP` 不是实际入口压力。入口校正及收敛诊断使用实际端口面几何面积均值。
8. **单位。** 准备态契约使用 K、Pa、m。接受 mm 单胞／壁厚的旧闭合调用须显式边界换算；内部单位不改变持久化 SI 场。
9. **端口边界。** `ComputeConfig.validate()` 规范化两个端口并调用共享校验。二维支持全部 ±x/±y，三维另支持 ±z；两个横向尺寸按正确域轴检查。开口之外外表面为静止无滑移壁，切向动量具有半格黏性壁通量，包括三维 z±。没有体积壁惩罚或求解后速度衰减。二维没有有限厚度 z 项；Nz=1 三维动量仍有两面 z 壁。主／交错原始开口比例直接来自最终实际网格上的原矩形，不由主比例平均得到。正原始重叠决定法向出口流和 PPE 支持，渐变轮廓独立。入口质量归一化和局部出口质量闭合继续生效。粗初始化重建原端口，按物理开口面积交集转移入口质量，延拓后恢复细出口支持；预算和初值身份不变。Richardson 不增加细网格 SIMPLE。
10. **真实焓归属。** 任意有序流体配对含 sCO2 时使用守恒焓核。核消费 SIMPLE 有符号交错面质量，并从边界焓通量算热负荷；不得以标量流量重建全截面 x 流。共享核要求显式两套面流量元组。数值参考测试的均匀流构造只在测试助手内。两维每个 sCO2 侧在入口和实际局部状态都遵守共享物性范围：**280–700 K、7.9–16 MPa 绝压**。2026-09-09 压力下限扩展不改变 EOS、独立 Nu/D-F 范围或验收，也不证明新增范围实验精度。生产 Picard 仅在 CO2 T(h,P) 使用 CoolProp BICUBIC。最终温度、耦合能量、出口反演和其他物性仍为 HEOS。精确 EOS 能量检查失败后，剩余迭代在 HEOS 收尾；重新回表可能在两个不动点间循环。每次热求解拥有自己的可变表状态；局部压力下 HEOS 焓界限确保域边界仍由 HEOS 检查。用表时，结果模型元数据记录 sco2_enthalpy_eos，含 `bicubic_iteration_heos_polish_v2` 和是否需要精确 EOS 收尾。这是近似迭代算法，不是实验标定。独立实验开关 `TPMSHX_SCO2_COMPRESSIBLE` 仅为三维 A 侧启用局部压力密度／黏度，并改变该侧压力初始化／包络。B 侧 sCO2 保留入口压力物性。该开关默认关闭，不实现完整可压缩连续方程，也不验证两侧对称可压缩模型。A 侧流动物性压力为 `P_ref_abs + P`，true-h 使用 `P_in - dP_face + P`，两锚点不保证相同。理想气体入口校正不验证该研究分支。将 ON/OFF 差异解释为更准确前，应比较真实入口压力、两锚点及质量／能量预算。
11. **当前 TM1 限制。** sCO2 分区和偏移仍被拒绝。空气／水保留上述合格 model-h 与 temperature 路线。Nz>1 时，端单元处理覆盖全部真实流体和固体端控制体。Tin 施加在开口入口面并使用半格导热；出口零梯度施加在外面。显式 CC 与 SIMPLE 调用方提供真实入口热容输运，同时保留 CC 内部格式。给定 B 仍为外部热储库。
12. **实验修正范围。** 空气小试件分支在 L=6..8 mm、t=0.3..0.5 mm 内插值，t=0.6 使用独立 HX 批次。sCO2 仅用 D/G-7-6 热侧 ok_dp 证据，K=K0，属于整机有效修正：均匀对称、无分区／delta／其他 L/t，也无独立冷侧拟合。按同热侧 ok_dp 成员、实测流量和实验流通面积在绝压下修正后，入口速度窗为 Diamond 0.5827..2.5396 m/s、Gyroid 0.6120..2.4705 m/s。sF 冻结为 6.313005350332494 和 7.608907691857889。D-F 为多孔区闭合，可配有效自定义端口中心、宽度和全部求解方向；直接实验证据仅对应全面 x 标定边界。水＋空气 D/G-7-6 实验是两个完整、不连通 TPMS 网络，delta=0。4 月 1 日上海空气直通／全面，水走错列局部开口；4 月 7 日互换网络。水和空气使用相同拓扑单侧流通面积，D 为 5.94e-4、G 为 6.50e-4 m²，不用 28/34 通道数倍率或几何面捷径。排除 G/水第 1 项 dp_nonphysical 和 D/水第 10/11 项 duplicate_row 后，生产水拟合用原高流量窗 u>=0.10 m/s，原成员不变。固定 K0 的水 RMSRE 为 D 6.84%／G 0.93%，sF 为 4.8928／4.1989，实测上界 0.2541／0.2232 m/s。配套 HX 空气用独立 sF：Diamond 1.8024228153853061 保留原批次；Gyroid 2.649010286988306 使用 4 月 1 日直通第 2–16 项、固定 CFD K0、实验端点平均温度和原一维可压缩压降相对误差拟合。4 月 7 日只评估接法迁移，不拟合此值。完整两维不再调其他倍率。来源、列、成员、速度口径和误差见[直通空气标定](model-resources.md)。ComputeConfig 独立选择各侧，允许九种有序空气／水／sCO2 配对及全部有效方向。混合配对可组合不同批次修正，这是模型组合，不是联合实验验证。每个 HX 有效侧仍需自身速度窗、0.182 × 0.042 × 0.042 m 域和 delta=0；自定义进出口位置／尺寸保留。每个活动侧均须符合自身范围，不静默回退。

`hx_velocity_bounds()` 保留活动标定／来源审计窗口。`hx_application_velocity_bounds()` 另提供批准的生产窗口，以下依次为 Diamond／Gyroid，单位 m/s：水 0.0139648..0.254055／0.0162341..0.225876；空气 3.88324..22.7599／3.91282..24.5467；sCO2 0.434925..2.53961／0.381408..2.47046。完整精度在选择器中。这些窗口覆盖已审查 7/0.6 mm 整机实测组合和获准端口验证，不覆盖任意 T/P/mdot 组合。两个范围、真实入口 u 和批准用途都保存在修正元数据。

<a id="extension-points"></a>

## 扩展位置

- 通过 `models/fluid_props.py` 增加流体；Nu 留在 `models/nu_correlations.py`，记录带版本资源，并经公共模块 API 使用。
- 新用户配置先加入 `domain/compute_config.py` dataclass，再在 UI 边界适配一次。
- 只有当前用途需要时，才在既有配置边界后增加求解行为。单个实现不引入工厂或额外接口。
- 每维保留一条生产主线；除明确测试低层核外，验证代码调用该主线。

## 本地数据

原始数据有意不进入 Git，按仓库相对路径定位：

```text
data/raw_data/
├── experiments/{air,water_air,sco2}/
├── cfd/
│   ├── water/
│   └── sco2/{Diamond,Gyroid}/
├── archive/{co2,water_air,sco2}/
└── plans/water/
```

重命名数据目录前，必须先更新使用精确路径的加载器。生成报告不能成为原始测量的第二权威来源。[数据目录](data-catalog.md)映射原文件名。工作簿名还参与已确认的水压力口径选择；重命名须同步更新注册表与调用方测试。
