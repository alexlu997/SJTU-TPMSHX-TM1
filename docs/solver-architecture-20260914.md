## 已确定的设计

完整求解是主线，快速设计和筛选/优化只迁移受影响的调用并回归。
保留 GUI、CLI、公开 API、正式配置/结果结构；内部旧接口和判据允许退役。
软件参考和比较容差可按解释清楚的差异更新。统一与性能的取舍由实际测量决定。
工质、几何、相态、关联式、物性适用域及实验精度目标维持现状。

## 结构与职责

| 修改对象 | 维护位置 | 此次处理 |
|---|---|---|
| 所有二维工质的动量求解 | `solvers/simple_solver.py`、`_kernels_simple_2d.py` | 共用既有 SIMPLE；删除旧判据分支 |
| 所有三维工质的动量求解 | `solvers/simple_solver_3d.py`、`_kernels_simple_3d.py` | 共用既有 SIMPLE3D；删除旧判据和不可用于 F2 的内部 Anderson |
| 两维度共同收敛语义和配置 | `solvers/_solve_common.py`、`domain/run_environment.py` | 统一 F2 默认值、配置优先级和旧选项拒绝；残差、连续确认和失败语义共用 |
| 工质物性与 Nu 分派 | `models/fluid_props.py` | 两维度直接使用 FluidModel；删除二维属性字典及重复 Nu/Pr 计算分支 |
| 外层温度/物性耦合 | `solvers/coupling_skeleton.py`、两维度 backend | 复用既有循环和 Ta/Tb/Ts 跟踪，保留各维度实际求解顺序和额外条件 |
| 热量离散 | `ltne_energy{,_3d}.py`、`ltne_enthalpy{_2d,_3d}.py` | 沿用温度、模型焓、真实焓三种已存在路线；二维真实焓已复用三维内核 |
| 准备与报告 | `preprocess/`、`postprocess/` | 保持实际网格、物理端口和原生状态的文件交接；后处理不补做求解 |

没有新增求解器框架、工质工厂或依赖。今后改动量精度，按维度维护一处内核；
改共同收敛规则维护一处 F2；改工质物性/关联式维护对应模型。
涉及不同热量形式时，仍需分别核验其方程和适用条件。

## 必须保留的差异

- 2D 无 z 壁面，热量单位 W/m；3D 有实际厚度和 z 壁面，单位 W。
- 二维、三维的网格、面数组和压力求解策略不同，不能只改数组维数就视为等价。
- 2D 模型焓包括无分区、无 offset 的水—水；3D 目前不包含该组合，且另有变物性、双流体、Nz、conservative、mask 限制。
- sCO2 真实焓与空气/水温度路线的物性来源、状态采样和 Pr 处理存在既有差异；本轮未更换物性来源。
- 2D 外层先 SIMPLE 后热量并松弛物性；3D 初始化 SIMPLE 后循环热量/物性/SIMPLE。最终状态与原生通量的捕获时机保留。
- 筛选保留其预算、3D frozen-B 模型和优化惩罚逻辑；F2 收敛不意味着筛选模型达到完整求解或实验精度。
